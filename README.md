# Weather_app
 Objective:
To develop a secure and user-friendly password generator that creates strong, random passwords based on user-defined length and complexity requirements.

Steps Performed:  
1. Designed a GUI for password generation.
2. Added password length and character-type options.
3. Generated random passwords using letters, numbers, and special characters.
4. Added password strength/complexity controls.
5. Added a Copy to Clipboard feature.
6. Added validation for password length and selected options.
7. Tested the application with different password requirements.

Tools Used:  
- Python
- Tkinter
- random module
- string module
- Clipboard functionality

Outcome:
Successfully developed an Advanced Password Generator that quickly creates strong and customizable passwords and allows users to copy them easily for secure use.
